# QueueLess — Phase 1

**Healthcare Navigation Platform** · B.Tech CSE Project · Incremental/Agile SDLC

## What is this?

Phase 1 of a 10-phase roadmap. This is the **full-stack skeleton** — frontend talks to backend, backend talks to database.

## Tech Stack

| Layer | Tech |
|-------|------|
| Frontend | HTML + CSS + vanilla JS |
| Backend | Node.js + Express |
| Database | SQLite |
| Auth | bcryptjs + JWT |
